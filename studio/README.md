# Studio — המוח של ערוצי הסרטונים

## איך ממשיכים מכל מחשב (3 צעדים)
1. `git clone https://github.com/ilia044-lang/-.git` (פעם אחת, או `git pull` אם כבר משובץ)
2. פותחים טרמינל בתיקייה ומריצים `claude`
3. אומרים: **"אני רוצה לעבוד על ערוץ ___"** (Era Mirror / BubiPop Kids / TikTok Trading)

Claude קורא לבד את `studio/STUDIO.md` ואת הדף של הערוץ, ויודע איך אתה אוהב לעבוד.

## מה כאן
| קובץ | תוכן |
|---|---|
| `STUDIO.md` | כללי עבודה, כלים, איך אתה אוהב להפיק (משותף לכל הערוצים) |
| `channels/era-mirror.md` | ערוץ ההיסטוריה |
| `channels/bubipop-kids.md` | ערוץ הילדים |
| `channels/tiktok-trading.md` | טיקטוק מסחר |
| `../skills-backup/` | הסקילים עצמם (BubiPop x2, trading-tiktok-video) |

## חשוב
- מה שמסומן **"לא הוחלט"** — לא נקבע עדיין. Claude ישאל, לא ימציא.
- המסמכים האלה מתעדכנים אחרי כל הפקה. אחרי שינוי: `./backup.sh`.
- סרטונים וקבצי וידאו גדולים **לא** נשמרים בגיטהאב. רק קוד, תסריטים, פרומפטים והחלטות.
